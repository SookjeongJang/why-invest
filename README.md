# Why Invest V0.3

V0.2 사용자 테스트 피드백을 반영한 버전입니다.

## 이번 변경
- 질문 버튼을 처음 누르면 화살표 뒤에 짧은 답이 나타납니다.
- 같은 버튼을 다시 누르면 다음 단계의 자세한 설명으로 이동합니다.
- 첫 클릭과 두 번째 클릭의 안내 문구를 표시합니다.
- 화면이 너무 갑자기 바뀌지 않도록 짧은 전환 효과를 추가했습니다.
- 다른 질문을 누르면 이전에 펼친 답은 닫힙니다.
