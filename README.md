# Why Invest V0.2

클릭 가능한 정적 웹 프로토타입입니다.

## 포함 기능
- 경제 주제 6개 선택
- 주제별 3단계 학습
- 브루마블 느낌의 탐험 보드
- 한 줄 기록 저장
- 브라우저 localStorage 자동 저장
- 기록 보기
- 기록 초기화
- PC/모바일 반응형

## GitHub에 교체하는 방법
1. 기존 저장소의 `index.html`, `styles.css`, `app.js`를 삭제하거나 덮어씁니다.
2. 이 폴더의 같은 이름 파일 3개를 저장소 최상단에 업로드합니다.
3. Commit changes를 누릅니다.
4. Vercel은 GitHub 변경을 감지해 자동 재배포합니다.
5. 배포가 끝난 뒤 기존 주소를 새로고침합니다.

`docs`, `design`, 기존 `README.md` 폴더/파일은 그대로 두어도 됩니다.
